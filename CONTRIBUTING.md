# Contributing / Como contribuir

## English

Contributions, improvements and forks are welcome under the [Apache License 2.0](LICENSE). Preserve applicable copyright and attribution notices, including the [NOTICE](NOTICE) file.

- Open an issue describing the change before large modifications.
- Keep each pull request focused; target the default `main` branch. Avoid unnecessary branches.
- Explain behavior changes, compatibility and manual test results.
- Keep code commented where it adds clarity, and maintain documentation in English and Brazilian Portuguese.
- Do not commit credentials, mailboxes, private messages or user profiles.
- Identify third-party code and its license before incorporating it.
- Follow semantic versioning where possible: `MAJOR.MINOR.PATCH`. Document user-visible changes in `CHANGELOG.md`.

## Português (Brasil)

São bem-vindas contribuições, melhorias e forks, conforme a [Apache License 2.0](LICENSE). Preserve os avisos de direitos autorais e atribuição aplicáveis, inclusive o arquivo [NOTICE](NOTICE).

- Abra uma issue descrevendo mudanças de maior impacto.
- Faça pull requests objetivos para a branch padrão `main`, evitando branches desnecessárias.
- Informe alterações de comportamento, compatibilidade e testes manuais.
- Comente o código quando isso melhorar a compreensão e mantenha a documentação em PT-BR e inglês.
- Não envie credenciais, caixas postais, mensagens privadas nem perfis de usuários.
- Identifique o código de terceiros e sua licença antes de incorporá-lo.
- Use versionamento semântico quando possível: `MAJOR.MINOR.PATCH`. Registre mudanças visíveis em `CHANGELOG.md`.
