# Mail Bounce

**Mozilla Thunderbird email redirect extension / Extensão de redirecionamento de e-mails para Mozilla Thunderbird**

[![License: Apache 2.0](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](LICENSE)

## English

Mail Bounce redirects email messages to one or several recipients while aiming to preserve the original sender and message content, unlike conventional forwarding.

### Features

- Redirect without opening a compose window.
- Quick recipient bar with up to six addresses and an additional free-form field.
- Redirect indicator in the message list.
- Support for multiple Thunderbird email accounts.
- Interface in English and Brazilian Portuguese.

### Installation

Download a published `.xpi` file from [Releases](https://github.com/aureliosrneto/Mail-Bounce/releases), open **Thunderbird → Add-ons and Themes → Install Add-on From File**, and select it. Check each release's compatibility with your Thunderbird version.

### Security and privacy

Review the extension permissions and verify recipients before redirecting sensitive mail. Redirecting does not guarantee successful delivery or that receiving servers will accept original sender authentication.

## Português (Brasil)

O Mail Bounce redireciona mensagens de e-mail para um ou vários destinatários, procurando preservar o remetente e o conteúdo originais, diferentemente do encaminhamento convencional.

### Funcionalidades

- Redirecionamento sem abrir a janela de composição.
- Barra rápida com até seis destinatários e campo livre adicional.
- Indicador de mensagens redirecionadas na lista.
- Suporte a múltiplas contas do Thunderbird.
- Interface em português brasileiro e inglês.

### Instalação

Baixe o arquivo `.xpi` de uma versão publicada em [Releases](https://github.com/aureliosrneto/Mail-Bounce/releases). No Thunderbird, acesse **Extensões e Temas → Instalar extensão de um arquivo**. Confira a compatibilidade de cada versão.

### Segurança e privacidade

Confira as permissões solicitadas e os destinatários antes de redirecionar mensagens confidenciais. O redirecionamento não garante a entrega nem a aceitação da autenticação do remetente original por todos os servidores.
