# Mail Bounce v0.3.23 — Release notes / Notas de lançamento

## English
- Explicit persistent Manifest V2 background processing.
- Improved startup/reload synchronization between the quick-bounce bar and its background listener.
- Brief wait for listener readiness instead of immediate failure.

## Português (Brasil)
- Processamento persistente explícito no background do Manifest V2.
- Melhor sincronização entre a barra de redirecionamento e o listener na inicialização/recarregamento.
- Breve espera pelo listener, em vez de falha imediata.
